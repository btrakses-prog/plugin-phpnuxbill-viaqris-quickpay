##CARA INSTALASI##
1. Pindahkan quickpay ke direktori root phpnuxbill
2. buka quickpay rename config.example.php ke config.php
3. ubah config.php sesuai phpnuxbill anda
4. pindahkan isi plugin ke direktory /system/plugin/ dan isi folder ui ke /system/plugin/ui/
5. pindahkan isi paymentegateway ke direktory /system/paymentgateway/ dan isi folder ui ke /system/paymentgateway/ui/
6. untuk mengakses quickpay https://link-billing.anda/quickpay
